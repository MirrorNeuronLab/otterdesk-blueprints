# Compatibility verifier

The integration and regression section compares staged service journeys across the captured baseline and candidate. Each journey identifies the first divergent handoff and preserves its observed values.

Choose **Sample verification** to run the bundled checks, or select a source folder and enter your approved JSON scope. Results are in `report.md`, `final_artifact.json` and the local web view.

[Reviewing a run](conversation_guide.md)

## Work with Software verifier suite

Join a saved group with Software verifier suite to receive approved compatibility assignments.
An assignment starts this co-worker on demand. Its messages and requests for input appear in the suite chat.
It verifies the assigned source snapshot and sends the result and evidence back
to the manager. A specialist can work entirely from its mailbox. If the inbox is empty,
it reviews a configured standalone source when available. Otherwise the run reports that it is waiting for an assignment.
