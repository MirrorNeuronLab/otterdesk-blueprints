# Bibblio learning and safety playbook

A review brief needs an observable learning objective, age band, practice opportunity, feedback behavior, success evidence, parent co-play guidance, and minimum personalization fields.

Use PASS only when the objective, activity, claims, and safety boundaries are clear. Use PASS WITH CONDITIONS for remediable constraints. Use REVISE for incomplete pedagogy or evidence. Use BLOCK for therapeutic, diagnostic, medical, exploitative, unsafe, or guaranteed-outcome proposals.

Review the complete story, activity, answers, visuals, audio, personalization, metadata, and parent-facing claims. Approval of a brief is never approval to publish generated content.
