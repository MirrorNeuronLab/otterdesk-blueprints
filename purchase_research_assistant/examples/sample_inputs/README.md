# Purchase Research Sample Inputs

Edit `purchase_request.txt` the same way you would write a short note to a
research assistant: say what you want to buy, add optional labeled constraints
or priorities, and paste any public links where research stopped. The bundled
note models a buyer screening three synthetic single-family homes in ZIP code
03755.

The sample is safe for fake/offline runs and demonstrates plain-text request
intake, public research leads, hard-constraint checks, five-year known-cost
comparison, disclosure triage, local evidence retrieval, missing-evidence
gates, and review-only output.

The candidate records are snapshots, not live listings. Prices, taxes,
insurance, condition notes, and availability must be independently verified
before any real-world use.

Replace or edit `purchase_request.txt`, then add approved local evidence such
as listings, quotes, fee schedules, inspection notes, fare rules, rental
disclosures, warranty documents, or comparison spreadsheets. Use only public
research URLs and do not include secrets or documents that the configured
runtime is not authorized to process.
