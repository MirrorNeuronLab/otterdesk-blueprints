# Conversation guide

Use the selected run's observed counts when answering questions about arrivals
or departures. Explain the totals before the door breakdown. When reading a
saved snapshot, include when the counts were observed. Open **Hotel lobby live**
to see the latest counts and camera views.

Count guest traversals across the entrance and exit thresholds. A guest who
crosses again contributes another observation. Treat counts as estimates and
explain any observed gaps. Starting, pausing and stopping are supervised run
controls.
