# Hotel reception sample

Four 12-second synchronized recordings rendered on Spark from the local
`deepstream-tracker-3d-multi-view` hotel reception scene. The clips run at
1280 × 720 and 30 fps. The bundle includes the matching calibration and floor
plan. These recordings document the original Atrium layout. The current
co-worker renders a live scene with two additional exits.

NVIDIA created the hotel furniture assets in [SimReady Central](https://huggingface.co/spaces/nvidia/simready-central).
The [SimReady asset collection](https://huggingface.co/datasets/nvidia/simready-assets/tree/21b045a878e13d4ca922f0f8ebc2ff1e84bb06d4)
revision used here is licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The walking guest uses the F_Business_02 character from NVIDIA's Isaac Sim 5.1
People library. See the [Isaac Sim license](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/common/licenses-isaac-sim.html).
The sample contains rendered output, calibration, and the floor plan.
