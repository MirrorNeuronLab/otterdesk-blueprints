# Synthetic Northstar history

SYNTHETIC EXAMPLE ONLY. The four JSON files encode a prior target, a changed
target with explicitly attributed execution E1, a second distinct execution E2,
and late corroborated installation evidence explaining the update. They do not
claim that default macOS logs contain these fields. No real host data is included.

After R-01: baseline observation, no case. After R-02: one target-change case,
one execution. After R-03: same case, two executions. After R-04: same case
explained by an independent installation receipt. Execution time remains October
1/5 even when evidence arrives later. Changing order or reimporting archives
must preserve the final supported behavior. Remove attribution or corroboration
and the stronger claim must weaken.
