# Bibblio Content Studio playbook

Accept only briefs with a current Learning Science decision of PASS or PASS WITH CONDITIONS. Produce the smallest useful batch, reuse reviewed structures, version every package, and record provenance and generation cost.

A complete package includes the learning objective, story architecture, practice opportunities, answer-key status, parent guidance, allowed personalization, accessibility needs, and required reviewers.

No draft is child-ready. Route the full package back to learning, safety, brand, licensing, accessibility, and founder review before publication.
