# Synthetic demonstration site context

SYNTHETIC EXAMPLE ONLY. This document describes an invented site for planner demonstrations. It is not the user's camera configuration, actual site policy, or a live finding. Do not apply these example rules to a real stream without the supervisor's explicit configuration.

The fictional Harbor workshop has a central walkway, a machinery area, and a loading doorway. Demonstration camera DEMO-CAMERA-A views the walkway and part of the machinery area. Occlusion behind equipment can hide people; a single frame cannot establish that someone left the site.

In this invented example, a supervisor asks to review visible people near the walkway and possible obstructions near the loading doorway. A target observation is evidence for review, not proof of unsafe behavior or unauthorized access. Repeated unchanged detections can be grouped under the configured cooldown; changed conditions should retain their own evidence.

For an explanation question, this synthetic site can illustrate how a monitoring instruction relates to a target and evidence. For a current status or findings question, use actual operator activity and timestamps instead of these invented scene details.
